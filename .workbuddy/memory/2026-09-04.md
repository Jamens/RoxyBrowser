## 从零搭建 RoxyBrowser Clone（Electron 指纹浏览器桌面端）

**需求**：对标 roxybrowser.cn（跨境电商防关联指纹浏览器），做桌面端产品，技术栈必须是 pnpm + TS + React，MySQL `root/1234560`。

**技术选型**：Electron 33 + electron-vite 2 + Vite 5 + React 18 + Antd 5 + React Router 6（HashRouter）+ Express + TypeORM + MySQL(127.0.0.1:3307, 库名 `roxy_browser` 自动创建)。Express 内嵌在 Electron 主进程，端口 39100（被占用则递增），同时作为本地业务 API 和对外自动化 API（`http://127.0.0.1:39100/api/v1/*`，令牌鉴权）。

**已实现功能**：环境管理（每环境独立 `persist:env-{id}` session）、指纹注入（UA/userAgentData/语言/时区/屏幕/CPU/内存/Canvas 噪声/WebGL Vendor-Renderer/Audio 噪声/WebRTC 禁用）、代理管理（HTTP/HTTPS/SOCKS5 + 连通性检测走 ip-api.com）、窗口模板、多窗口同步（滚动/点击/输入广播）、团队与角色权限、账号中心、操作日志、自动化 API v1 + 页面内文档。默认账号 `admin/123456`。

**爬取的官网要点**（RoxyBrowser）：六大场景（跨境电商/海外社媒/广告投放/联盟营销/数据爬取/SEO）、核心卖点（指纹隔离 + RoxyIP 代理池）、团队空间与角色权限、窗口模板、一键随机指纹、资料迁移、日志面板（标注操作人）、API 自动化、宣称通过 Fingerprint/CreepJS 检测、SOC2/ISO27001 等合规。

## 关键坑与解法（重要）

1. **pnpm 11 构建脚本**：`package.json` 里的 `pnpm.onlyBuiltDependencies` 已被废弃，改写到 `pnpm-workspace.yaml` 的 `allowBuilds: {electron: true, esbuild: true}`；electron 二进制下载走 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，需 `pnpm install --force` 重跑一次才恢复 `.pnpm` 内部链接。
2. **esbuild 不支持 `emitDecoratorMetadata`**：TypeORM 装饰器必须给每个 `@Column` 显式 `type`（如 `type: 'varchar'`），否则运行时报 `ColumnTypeUndefinedError`。
3. **列名**：没启用 snake_case 命名策略 → 列名即属性名（`teamId` 不是 `team_id`），QueryBuilder 里写错列名会导致查询报错 + 请求挂起。
4. **Express 4 不捕获 async 异常**：加了 `wrapAsync(router)` 统一包裹 handler，异常转 500，避免请求永久挂起（这个坑导致了很久的排查）。
5. **`ELECTRON_RUN_AS_NODE=1`**（宿主 IDE 环境会设置）：会让 electron 以纯 Node 模式运行，`require('electron')` 返回路径字符串，`ipcMain` 为 undefined。启动前必须 `env -u ELECTRON_RUN_AS_NODE`（PowerShell：`$env:ELECTRON_RUN_AS_NODE=$null`）。
6. 沙箱环境里 GPU 进程不可用，测试启动需加 `--disable-gpu --no-sandbox`。

**验证结果**：healthz OK、登录 OK、创建环境(HTTP 200，随机指纹 tz/UA 正常)、打开窗口(状态 → running)、自动化 API 建环境/列环境 OK、操作日志记录 OK。
